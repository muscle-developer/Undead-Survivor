# Undead-Survivor
# 뱀파이버서바이벌 프로젝트

마스터 브랜치에 관련 프로젝트 있습니다.

- 혼자서 게임의 처음부터 끝까지 단계별로 진행해 볼 수 있었습니다.
- InputSystem 을 사용한 플레이어의 이동을 구현해 볼 수 있었습니다.
- 플레이어와 적의 애니메이션을 적용하고 재활용에 대해 공부할 수 있었습니다.
- 오브젝트 풀링 및 맵의 재활용과 같은 최적화에 대해 공부할 수 있었습니다.
- 매니저를 통해 게임을 쉽고 편하게 관리하는 방법을 공부할 수 있었습니다.
- 스크립터블 오브젝트를 사용하여 다양한 데이터를 에셋처럼 저장시켜 활용할 수 있었습니다.
- Playerprefs를 사용하여 간단한 정보 저장 및 활용할 수 있었습니다.
- 매니저를 통해 오디오를 쉽게 관리할 수 있었습니다.
- UI와 각종 버튼, 토글등 이벤트들을 사용할 수 있었습니다.
- 게임 플레이를 통해 QA를 하고 버그를 수정할 수 있었습니다.
